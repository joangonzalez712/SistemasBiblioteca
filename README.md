# Sistema de Gestión de Biblioteca

Proyecto desarrollado para la asignatura Programación Avanzada.

## Tecnologías

- C#
- Windows Forms
- SQL Server
- ADO.NET

## Funcionalidades

- Gestión de autores
- Gestión de editoriales
- Gestión de usuarios
- Gestión de libros
- Préstamos y devoluciones
- Reportes

## Ejecución

1. Ejecutar el script SistemaBiblioteca.sql
2. Abrir SistemaBiblioteca.sln
3. Ejecutar el proyecto
